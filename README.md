# Apex GT

Juego de carreras 3D en el navegador (Three.js): 3 pistas, obstáculos, autos que se
desbloquean ganando, control por inclinación en celulares y salas en línea de hasta 4 pilotos.

- `index.html` y `assets/`: el juego (se publica con GitHub Pages).
- `server/`: servidor de salas (Node.js, sin dependencias) que corre en Render.

## Créditos

- Modelo 3D: "Generic Sport Car Low Poly" por Han66st, licencia CC BY 4.0.
- Sonidos de derrape y choque: Kenney (CC0). Motor: domasx2 (CC0).
- Música original del juego.
